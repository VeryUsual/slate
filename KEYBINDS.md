# WM-Level/Global-Level
Keybinds that have to do with the window manager or global Slate-level key bindings are prefixed by the `space` key. This prefix will be called the `global leader key` or just `global leader`.

<kbd>global leader</kbd> + <kbd>s</kbd> + <kbd>v</kbd>


# Window Level
Keybinds that have to do with any given individual window are not prefixed.
